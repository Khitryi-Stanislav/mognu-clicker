# 🎯 Я тебя МОГНУ — Кликер для Яндекс Игр

Абсурдный кликер про мем 2026 года с тиктокершами, достижениями и мульти-слойным геймплеем.

## 🚀 Особенности

✅ **8 уровней** с медленной прогрессией (0→2500 кликов)  
✅ **4 типа улучшений** с растущей стоимостью  
✅ **10 достижений** для мотивации  
✅ **Реклама за бонусы** — x2 доход на 30 секунд  
✅ **Дневной бонус** — +20% каждые 24 часа  
✅ **Поделиться результатом** — интеграция с соцсетями  
✅ **Облачное сохранение** — синхронизация через Яндекс SDK  
✅ **Частицы и эффекты** — в��зуальная обратная связь  
✅ **Адаптивный дизайн** — работает на всех мобильных

## ⚙️ Установка

1. **Клонируй репозиторий:**
   ```bash
   git clone https://github.com/Khitryi-Stanislav/mognu-clicker.git
   cd mognu-clicker
   ```

2. **Добавь ассеты:**
   - Положи PNG-файлы персонажей в `assets/characters/1.png` ... `8.png`
   - Положи MP3-трек в `assets/ya-tebya-mognu.mp3`
   - Положи иконки в `assets/icon-*.png` и скриншоты

3. **Открой локально:**
   ```bash
   # Через простой HTTP сервер (Python 3)
   python -m http.server 8000
   # Затем откройи http://localhost:8000
   ```

## 📤 Загрузка на Яндекс Игры

### Требования Яндекса:
- ✅ Работает на мобильных (есть адаптивность)
- ✅ Иконка 512x512 PNG
- ✅ 2-3 скриншота 1080x1920 PNG
- ✅ Сохранение прогресса (реализовано через localStorage + Яндекс SDK)
- ✅ Поддержка полноэкранного режима
- ✅ Описание 200-500 символов на русском

### Шаги загрузки:

1. **Перейди на** https://games.yandex.ru/developer
2. **Создай новый проект** → выбери тип "HTML5 Игра"
3. **Загрузи файлы:**
   - Все файлы репо (кроме .git и node_modules)
   - Убедись что `manifest.json` на корневом уровне
4. **Заполни мета-данные:**
   - Название: "Я тебя МОГНУ"
   - Описание: "Абсурдный кликер про мем 2026 года с тиктокершами"
   - Иконка: `assets/icon-512.png`
   - Скриншоты: `assets/screenshot*.png`
5. **Тестирование:** Яндекс даст эмулятор для проверки
6. **Отправь на модерацию** → ждёшь 3-5 дней

## 🎮 Геймплей

### Основной цикл:
1. **Кликай** по персонажу → получай могны
2. **Покупай улучшения** → увеличивай доход за клик и пассивный заработок
3. **Открывай достижения** → получай мотивацию продолжать
4. **Смотри рекламу** → получай x2 доход на 30 сек
5. **Достигай уровней** → персонаж меняется, имя растёт
6. **Максимизируй** — цель: все улучшения на максимум

### Улучшения:
- **Ритм** (+1 сила клика) — самое дешевое, базовое
- **Комбо 6-7** (шанс x2) — редкие удачи
- **Могн-помощник** (+0.25/сек) — пассивный доход
- **Серия без пауз** (+0.1/сек) — долгосрочный буст

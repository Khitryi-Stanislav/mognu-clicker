# Я тебя МОГНУ — прототип

Обновлённая версия:

- один способ клика — по самому персонажу;
- 8 уровней и 8 изображений, после восьмого персонажи зацикливаются;
- более медленная прогрессия: 0–100, 100–200, 200–500, 500–700, 700–1000, 1000–1400, 1400–1900, 1900–2500 кликов;
- ослабленные и дорогие улучшения;
- фоновые «6–7» и частицы при клике;
- музыка стартует от клика и останавливается после паузы.

## Ассеты

Положите предоставленные изображения в `assets/characters/1.png` … `8.png`, а легально лицензированный аудиофайл трека — в `assets/ya-tebya-mognu.mp3`.

Права и разрешения на использование изображений людей, названий и музыки должны быть подтверждены правообладателями отдельно. В репозиторий добавлен только код: изображения из чата и аудио по внешней ссылке автоматически в GitHub не загружаются.

## Запуск

Откройте `index.html` локально или опубликуйте репозиторий через GitHub Pages. Для браузерного запуска музыки нужен первый клик пользователя — это ограничение autoplay.

# 🎯 Я тебя МОГНУ - Кликер

Абсурдная игра-кликер про могнутие для Яндекс Игр!

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере
2. Начните кликать на персонажа
3. Зарабатывайте "могны"
4. Покупайте улучшения
5. Смотрите, как персонаж эволюционирует

## 🎮 Геймплей

### Основная механика
- **Клик** - получи 1 могн (зависит от уровня и улучшений)
- **Уровень** - повышается каждые 10 кликов, персонаж меняется
- **Улучшения** - покупай модули для увеличения дохода

### Уровни персонажа
1. **Уровень 1-4** - Новичок-Могн 😊
2. **Уровень 5-9** - Уверенный Могн 💪
3. **Уровень 10-19** - Могн-Босс 🔥
4. **Уровень 20-49** - Могн-Магнат 💰
5. **Уровень 50-99** - Космический Могн 🚀
6. **Уровень 100+** - Абсолютный Могн ⭐

### Улучшения

| Название | Эффект | Начальная цена |
|---|---|---|
| **Автомогн** | +0.1 могнов в сек | 10 |
| **Супер-Могн** | +50% к клику | 50 |
| **Мегамогн** | +100% к клику | 200 |
| **Пассивный Могн** | +1 могн в сек | 100 |

## 💾 Сохранения

Игра автоматически сохраняется в `localStorage` каждые 5 секунд.
